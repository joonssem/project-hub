# 발표 프리셋·데이터 편집 검증

2026-10-13

## 변경

- JSON 배열 직접 편집을 프리셋 입력 폼으로 대체했다.
- 프리셋 추가·삭제, 프로젝트 추가·제외, 위·아래 순서 변경, 실제 표시 순서 미리보기를 지원한다.
- JSON 붙여넣기와 내보내기 내용 확인·전체 선택·다운로드를 제공한다.
- 실패한 가져오기는 기존 데이터를 유지하고, 유효한 데이터 대체 전 현재 변경이 있으면 확인한다.

## 검증 결과

- 테스트 fixture를 관리자 탭에만 적용했다. 원본 data/projects.json은 바꾸지 않았다.
- 프로젝트 위로 이동, 제외 후 재추가, 이름 변경을 확인했다.
- 프리셋 추가·삭제와 중복 ID 적용 거부를 확인했다.
- 내보내기 화면의 JSON에 편집한 이름과 `game → teacher → lesson` 순서가 반영됐다.
- 내보낸 JSON 내용을 붙여넣어 다시 가져오는 과정이 성공했다.
- 허용되지 않은 privateNotes 필드가 있는 JSON은 거부됐고 기존 3개 목록을 유지했다.
- 임시 로컬 QA 서버에서 최초 JSON 요청을 503으로 응답시킨 뒤, 다시 불러오기를 눌러 정상 카드로 복구했다.
- 이미지 404 응답 시 대체 그래픽이 표시됐다.
- 360px 프리셋 편집 화면에서 가로 넘침이 없음을 확인했다.
- [실제 원본 데이터의 편집 화면](preset-editor.jpg)을 저장했다.

## 검증 제한

파일 업로드는 Chrome 확장의 파일 URL 접근 권한이 없어 자동화가 실패했다. 권한을 변경하지 않았다. 파일 다운로드는 자동화의 완료 이벤트를 받지 못했다. 따라서 파일 선택 업로드·다운로드의 전체 동작은 수동 확인이 남아 있다. JSON 내용 내보내기와 붙여넣기 재가져오기는 실제 브라우저에서 검증했다.

임시 QA 서버는 종료했다. 브라우저는 실제 원본 데이터를 불러온 관리자 화면으로 되돌렸다. 실제 실행 주소와 외부 배포는 여전히 미확정이다.
