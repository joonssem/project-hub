# P0 구현·검증 기록

2026-10-13

## 이번 변경

- 미니게임 플랫폼 README의 공개 기능 설명을 바탕으로 실제 카드를 정리했다. 다른 저장소의 코드는 수정하지 않았다.
- 예시 카드를 운영 JSON에서 제거하고 테스트 전용 fixture로 분리했다.
- 대표 이미지, 검색 조건 초기화, 로딩·실패·재시도, 잘못된 프리셋 URL 보정, 본문 건너뛰기와 결과 건수 안내를 추가했다.
- 공개 파일 6개만 dist/에 복사하는 빌드와 운영·복구 절차를 마련했다.

## 확인한 결과

- `npm run check`: 문법 검사와 테스트 4개 통과.
- `npm run build`: 공개 파일 6개 생성. 원본 문서와 테스트 fixture는 제외.
- 빌드 서버의 HTML·JS·CSS·JSON·SVG는 HTTP 200, 문서·테스트·없는 JSON은 404.
- Chrome에서 학생·교사·발표·관리자 화면을 확인했다.
- 없는 검색어의 0건 안내와 조건 지우기, 교사용 활용 안내 열기를 확인했다.
- 잘못된 preset 주소가 training으로 보정되고 실제 선택 화면과 URL이 일치했다.
- 관리자에서 javascript 실행 주소 적용이 거부되고 원본 카드가 유지됐다.
- 360px 화면의 DOM 너비가 화면 너비를 넘지 않고 대표 이미지가 로드됐다. 검색 필드에서 Tab 키로 태그 필터로 이동했다.
- 1280px 화면에 가로 넘침이 없음을 확인했다. [화면 캡처](student-desktop.jpg).

## 아직 확인하지 않은 사항

- 실제 미니게임 실행 주소와 해당 서비스의 접속 동작: 주소 미확보.
- 외부 배포와 외부 URL에서의 검증: 호스팅 미선정.
- 실제 학생·교사의 첫 사용과 성공 지표: 사용자 확인 필요.
- 네트워크 장애 시 재시도와 이미지 실패의 브라우저 재현: 구현했지만 이번 실제 브라우저 검증에서는 재현하지 않음.
- 관리자 JSON 다운로드·파일 업로드의 브라우저 전체 흐름: 데이터 계약 테스트만 완료.

후속 검증에서 네트워크 실패 후 재시도, 이미지 실패 대체 표시, JSON 내용 내보내기·붙여넣기 재가져오기를 확인했다. 파일 선택 업로드·다운로드 완료 검증은 여전히 남아 있다. 상세는 [프리셋·편집 검증](preset-review.md)을 참조한다.

따라서 P0 전체 완료 또는 외부 공개 준비 완료로 간주하지 않는다. 로컬 실행·배포 파일 준비와 주요 화면 검증까지 완료한 상태다.
