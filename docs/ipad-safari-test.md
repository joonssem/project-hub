# 학생 iPad Safari 검증 항목

GitHub Pages 배포가 성공한 뒤 실제 학생 기기로 수행한다. 아직 실제 iPad 테스트를 실행한 기록이 아니다.

기록: 날짜 / iPad 모델 / iPadOS 버전 / Safari 버전 / 학교 Wi-Fi / 배포 URL / 결과와 화면 캡처. 개인정보나 게임 참가 학생 이름은 기록하지 않는다.

| 번호 | 테스트 | 통과 기준 | 결과 |
| --- | --- | --- | --- |
| 1 | 배포 URL 처음 열기 | 학생 화면·카드·대표 이미지 정상 표시, 로딩 후 목록 표시 | 미실행 |
| 2 | 세로·가로 회전 | 카드와 필터 잘림·가로 넘침 없음, 조작 가능 | 미실행 |
| 3 | 검색 입력·키보드 닫기 | 한글 입력 가능, 입력 시 불필요한 확대 없음, 결과 갱신 | 미실행 |
| 4 | 태그 선택·빈 결과·초기화 | 검색·태그 조합과 초기화가 정확히 동작 | 미실행 |
| 5 | 실행 링크 탭 | 저장소가 아닌 실제 게임이 새 탭에서 열리고 방 만들기·들어가기 표시 | 미실행 |
| 6 | 원래 허브 탭으로 돌아오기 | 허브 목록이 남아 있고 다시 실행 가능 | 미실행 |
| 7 | 교사용 화면 | 교사 공개 카드와 활용 안내 표시, 저장소 링크와 실행 링크 구분 | 미실행 |
| 8 | 프리셋 주소 직접 열기·새로고침 | 지정 프리셋과 순서 유지, 하위 경로의 자산 정상 로드 | 미실행 |
| 9 | 잘못된 프리셋 주소 | 기본 프리셋으로 보정, 빈 페이지 없음 | 미실행 |
| 10 | 네트워크를 끊고 처음 접속 후 재연결 | 실패 안내와 재시도 제공, 연결 복구 후 목록 표시 | 미실행 |
| 11 | 잠금·해제 후 Safari 복귀 | 허브 목록·탭 사용 가능. 연결 게임의 복귀는 별도 게임 검증 | 미실행 |
| 12 | 학생에게 목표 게임 찾기 요청 | 교사 추가 설명 없이 30초 내 카드 찾고 실행 | 미실행 |

학교 네트워크가 GitHub Pages 또는 연결 게임을 차단하는지도 확인한다. 호스팅과 연결 게임의 장애를 구분해서 기록한다. 학생·교사 공개와 프리셋은 접근 제한이 아니라는 점을 설명한다.

관리자 데이터 편집·Files 앱 다운로드·파일 재가져오기는 별도 교사용 기기 테스트로 수행한다. 수정 전 원본 백업, 일부 값 수정, 내보내기, 재가져오기, 직전 목록 복원, 원본 교체·재배포까지 확인한다. Safari의 탭 종료 경고에만 의존하지 않고 편집 직후 내보내기를 수행한다.
