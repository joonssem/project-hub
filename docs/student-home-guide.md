# 자료 보관함과 학생 홈 운영

2026-10-21 · 로컬 구현 · 공개 배포 전

## 확인된 요구

내가 만든 웹앱, 인터넷 학습 자료, 다른 교사의 자료를 계속 수집하고 검색 가능한 보관함에서 관리한다. 학생에게는 일부만 보여주며, 독도 교육 주간처럼 특정 기간에 필요한 자료를 최상단에 제목·소개·썸네일과 함께 크게 배치한다. 다음 주에는 다른 특집으로 전환하거나 일반 자료 목록으로 돌아간다.

## 사용 순서

1. `?view=admin`에서 **자료 수집**을 누른다. 자료명·링크·설명·썸네일 주소·태그·출처·제작자 또는 제공처를 입력한다. 저장소 주소는 선택 사항이며 새 자료는 학생·교사 표시가 꺼진 보관 상태로 시작한다.
2. 보관함에서 이름·설명·태그·제작자로 검색한다. 출처, 태그, 학생 표시 상태로 목록을 좁힌다.
3. **학생 목록** 스위치를 켜면 일반 학생 목록에 나타난다. 끄면 보관함에 남고 학생 목록과 특집에서 제외된다. 전체 숨김 자료는 수정 화면에서 숨김을 해제해야 한다.
4. **학생 홈 구성 → 주제 특집 추가**에서 제목·소개·대표 이미지·게시 기간을 정하고 자료를 검색해 추가한다. 자료와 특집의 순서는 위·아래 버튼으로 조정한다. **이 특집 사용**을 켜고 **탭에 적용**한다.
5. **특집 아래에 일반 학생 자료 목록도 표시**를 끄면 특집 기간에는 해당 특집 자료만 나온다. 켜면 일반 학생 목록도 나온다.
6. **학생 화면 미리보기**에서 날짜를 바꿔 지금·다음 주·특집 종료 후 구성을 확인한다. 현재 탭의 편집 내용을 사용한다.
7. **JSON 내보내기 → `data/projects.json` 교체 → `npm run check` → `npm run build` → 배포**까지 해야 방문자에게 반영된다.

독도 자료를 소개하려면 실제 링크를 등록하고 학생 표시를 켠 뒤 ‘독도 교육 주간’ 특집에 넣는다. 다음 특집도 다른 기간으로 미리 만들어 두면 전환된다. 확인하지 않은 독도 링크나 예시 자료를 공개 데이터에 추가하지 않았다.

## 게시 규칙

- 한국 시간의 달력 날짜로 시작일·종료일을 모두 포함한다. 날짜를 비우면 해당 방향으로 기간 제한이 없다.
- 기간이 겹치면 목록에서 위에 있는 사용 가능한 특집 하나를 표시한다.
- 학생 표시가 꺼져 있거나 전체 숨김인 자료는 특집에서도 제외한다. 표시할 자료가 없는 특집은 건너뛴다.
- 활성 특집이 없으면 일반 학생 목록으로 복귀한다. 일반 목록 표시를 꺼 두었더라도 이때는 목록이 나타난다.
- 배포한 설정 안에서 날짜에 따라 화면이 전환된다. 예약 실행 서버는 없다. 열린 학생 탭도 한국 날짜 변경과 탭 복귀 시 기간을 다시 확인한다. 기기의 시계가 정확해야 한다.
- 연수 프리셋과 교사 화면의 기존 표시 규칙은 유지한다.

## 저장과 데이터

실제 DB·관리자 인증·웹 저장은 아직 없다. 현재 보관함은 공개 JSON을 표로 관리하는 화면이다. 새로고침하면 내보내지 않은 변경이 사라진다. 보관·숨김 자료도 공개 JSON에 포함되므로 비공개 메모를 넣지 않는다. 저장 즉시 사이트를 갱신하고 비공개 보관함까지 운영하려면 관리자 인증과 서버 저장·공개 데이터 분리가 다음 단계다.

썸네일 주소는 직접 입력한다. 자동 설명·이미지 수집, 이미지 업로드, 드래그 정렬은 포함하지 않는다.

데이터 v3의 추가 필드:

- 자료 `source`: `own` / `teacher` / `web` / `unknown`. `creator`: 공개 제작자·제공처.
- `studentHome`: `showLibrary` boolean, `features` 배열.
- 특집: `id`, `title`, `description`, `image`, `enabled`, `startDate`, `endDate`, `projectIds`. 날짜는 빈 문자열 또는 유효한 `YYYY-MM-DD`. 배열 순서가 특집 우선순위와 자료 표시 순서다.
- v1·v2 가져오기는 기존 자료·프리셋·공개 설정을 보존하며 출처 미분류·빈 제작자·기본 학생 홈을 추가한다. 내보내기는 v3다.

## 확인

자동 검사 13개와 빌드를 통과했다. Chrome에서 보관함, 특집 추가·자료 선택·기간 입력·적용, 예약 날짜 미리보기, 종료 후 기본 화면, 학생 스위치에 따른 미리보기 변경을 확인했다. 실제 배포와 실제 iPad 검증은 수행하지 않았다.
